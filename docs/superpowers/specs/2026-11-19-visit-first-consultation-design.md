# Visit-first consultation

The existing visit is the work item. The Consultation page brings the template, clinical sections, recorded sources and record-note review into one workflow. Keep the consultation, GP examination and AI access rules.

Use GitHub Issues' placement of status and actions above the record, with the app's section header, teal primary button, neutral surfaces and compact secondary controls. Start with the wireframe approved in conversation. On phones, controls wrap and every field stays in a single column. Show per-visit dictation sources in a closed disclosure by default.

Ship dental consultation, general SOAP and recheck starters. Practice owners can duplicate, name, reorder and archive templates, preview a fictional case and set the practice default. A visit stores the selected layout so edits and archives preserve historical output. Existing source identifiers remain stable for dictation, reports and PIMS. Existing visits without a template retain their current order.

Link the editor, template library and note review to the searchable Help Center. A separate Consults queue can use the same visit records in a future change.
