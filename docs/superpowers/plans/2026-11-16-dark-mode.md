# Dark Mode Implementation Plan

> **For agentic workers:** Use superpowers:executing-plans to implement task by task.

**Goal:** Add remembered System / Light / Dark appearance across the app and SVG diagrams.

**Architecture:** One document theme resolved by a small preference store. Existing semantic/iOS tokens provide surfaces, text, controls and clinical colors; SVGs use dedicated tokens with light export fallbacks.

**Tech Stack:** React, TypeScript, CSS custom properties, i18next, Vitest.

**Spec:** docs/superpowers/specs/2026-11-16-dark-mode-design.md

## Global constraints

Preserve teal clinical design, 44px phone controls, all five UI languages and light PDF/print output. No changes to persisted clinical drawings or image pixels.

## Review focus

OS changes with a manual override; inaccessible or invalid storage; reload/cross-tab synchronization; dark SVG export; narrow-screen navigation and native appearance overrides.
