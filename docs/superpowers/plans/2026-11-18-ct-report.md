# CT report implementation plan

**Goal:** Add an independent CT report below Radiology report in Imaging, matching the established single-editor design with CT guidance and guarded AI refinement/Undo/review/export.

**Design:** Reuse the existing clinical editor and GitHub/Atlassian compact form/action hierarchy. One free-text field, CT-specific optional prompts inside it, Refine with AI and language selector. Separate CT text and metadata; no image interpretation or inferred scan/contrast details. Existing radiology dictation routing remains unchanged by this request.

**Architecture:** Reuse RadiologyReportSection through an explicit modality adapter that maps CT storage fields to the already-tested editor contract and maps updates back to CT fields only. CT request construction takes only CT text and identifies the modality, using the existing authenticated report-refinement service/model setting. Add bounded optional CT snapshot fields and integrate them with autosave, record/PIMS sections, client-report facts, PDFs and admin read-only views. No migration, deployment or new voice prompt required.
