# ToothOps iOS App Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship the existing ToothOps web app as a universal (iPhone + iPad) US App Store app with native features, from the same codebase, without changing web behavior.

**Architecture:** Capacitor wraps the Vite build (`build/`) in a native iOS shell under `ios/`. All app-only behavior branches through one helper, `isNativeApp()`; when it is false, every code path is exactly today's web path. Native capabilities come from Capacitor plugins wrapped in small `src/native/*` modules that no-op (or fall back to web behavior) off-device.

**Tech Stack:** React 19, Vite 8, TypeScript, Vitest, Supabase JS v2, Capacitor 7 (`@capacitor/core`, `cli`, `ios`, `app`, `browser`, `camera`, `filesystem`, `share`, `haptics`, `status-bar`, `splash-screen`, `keyboard`), `@capacitor-community/apple-sign-in`, `@aparajita/capacitor-biometric-auth`, `@capacitor/assets` (dev).

**Spec:** `docs/superpowers/specs/2026-11-12-ios-app-design.md`

## Global Constraints

- Web behavior must be unchanged when `isNativeApp()` is false; the full existing suite (`npm test`) and `npm run build` must pass after every task.
- App ID `app.toothops.ios`; app name `ToothOps`; custom URL scheme `toothops`; auth return URL `toothops://auth-callback`.
- Website origin for links that leave the app or go into emails: `https://toothops.app/` (constant `WEB_ORIGIN`).
- No prices, plan upsells, checkout, billing portal, or Stripe links anywhere in the app.
- Login screen link copy: `New to ToothOps? Sign up at toothops.app` (opens `https://toothops.app/` in the system browser).
- Apple hint copy (under the Apple button, app and web): `Already have an account or were invited? Sign in with your email.`
- Inactive-plan copy: heading `Your plan isn't active`, body `Manage it at toothops.app.` — no link, no button besides sign out.
- Offline billing grace: **7 days** since last successful billing check.
- Face ID lock after **5 minutes** in background.
- Limit messages are plain facts, e.g. `This chart has reached its 10-image limit.`
- No push notifications.
- Commits go to the bazhip GitHub account; branch `ios-app` off `origin/main`.

## Review Focus

1. **OAuth return while the app was killed** — tapping the magic link / finishing Apple-Google in the browser must open the app and sign in even on cold start (`App.getLaunchUrl()` as well as `appUrlOpen`). Test in Task 2.
2. **Offline launch with a stale or missing cache** — no cache or cache older than 7 days must show the existing "Couldn't check your subscription" screen, not a blank screen or the app. Test in Task 3.
3. **Share sheet cancelled** — dismissing the share sheet must not surface an error toast. Test in Task 4.
4. **Pencil + palm** — a resting palm while drawing with Pencil must not add strokes; finger drawing must still work on an iPad with no Pencil. Test in Task 7.
5. **Team-invite emails sent from the app** — the `redirectTo` must be `https://toothops.app/`, never `capacitor://localhost`. Test in Task 2.
