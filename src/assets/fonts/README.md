# PDF fonts

Liberation Fonts 2.1.5, unmodified regular and bold Sans, Serif, and Mono.
Source: https://github.com/liberationfonts/liberation-fonts/releases/tag/2.1.5
Distributed under the SIL Open Font License in `LICENSE_LIBERATION`.

These fonts cover Hungarian and Romanian diacritics missing from the standard
PDF fonts. They are loaded only for those locales and embedded as subsets.
